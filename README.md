# ✈️ 국내 여행지 추천 프로그램 (GUI)

여행 날짜를 고르면 **Google Gemini**가 그 시기에 어울리는 국내 여행지와 하루 일정을 추천하고, **카카오 로컬 API**가 해당 지역의 맛집을 찾아 주며, 결과를 **마크다운 여행 리포트**로 자동 저장하는 Python 데스크톱 프로그램입니다.

```text
날짜 선택 ─▶ [1] Gemini 추천 (도시·날씨·행사·일정) ─▶ [2] 카카오 맛집 검색 ─▶ [3] 리포트 저장 및 화면 표시
```

> 터미널에서 쓰는 CLI 버전(`main.py`)도 함께 제공합니다. → [9. CLI 버전](#9-cli-버전)

---

## 1. 주요 기능

| 기능 | 설명 |
|---|---|
| 날짜 선택 | 년/월/일 드롭다운, `오늘` 버튼. 입력 형식 오류가 생기지 않음 |
| AI 여행지 추천 | 도시 1곳, 날씨, 행사, 추천 이유, 하루 일정(오전/점심/오후/저녁) |
| 맛집 검색 | 음식점 5곳의 이름, 종류, 주소, 카카오맵 링크. 더블클릭으로 바로 열기 |
| 3개 결과 탭 | 요약 / 맛집 / 리포트 |
| 리포트 저장 | 마크다운(`.md`)과 원본 데이터(`.json`)를 `results/`에 자동 저장 |
| 편의 기능 | 결과 폴더 열기, 리포트 클립보드 복사 |
| 안정적인 동작 | 실행 중에도 창이 멈추지 않음, 오류 원인별 안내, 필요한 경우에만 자동 재시도 |

## 3. 프로젝트 구조

```text
my_travel_app/
├── .env                          # API 키 보관 (Git 제외 필수)
├── .gitignore                    # .env, results/ 등 제외 설정
├── travel_recommender_gui.py     # GUI 버전 (이 문서의 주 프로그램)
├── main.py                       # CLI 버전 (선택)
├── README.md                     # 프로그램 설명서
└── results/                      # 실행 결과 자동 저장 폴더
    ├── result_YYYYMMDD_HHMMSS.json   # 원본 데이터 (AI 추천 + 맛집 + 오류 기록)
    └── report_YYYYMMDD_HHMMSS.md     # 최종 마크다운 여행 리포트
```

`results/` 폴더는 항상 **프로그램 파일이 있는 폴더**에 만들어집니다. 어디서 실행해도 저장 위치가 바뀌지 않습니다.

## 4. 개발 및 실행 환경

- Python 3.10 이상
- 의존성 패키지: `google-genai`, `python-dotenv`, `requests`
  (Pydantic은 `google-genai`와 함께 설치되고, GUI 라이브러리 `tkinter`는 Python에 기본 포함되어 있습니다.)

```bash
pip install google-genai python-dotenv requests
```

## 5. API 키 설정 (.env)

프로젝트 폴더에 `.env` 파일을 만들고 키를 작성합니다. **따옴표 없이** 적는 것이 가장 안전합니다.

```env
GEMINI_API_KEY=your_gemini_api_key_here
KAKAO_REST_API_KEY=your_kakao_rest_api_key_here

# 선택: 사용할 Gemini 모델명 (생략하면 코드의 기본값 사용)
GEMINI_MODEL=사용할_모델명
```

- 카카오 키는 **REST API 키**를 사용해야 합니다. (다른 종류의 키를 넣으면 401 오류)
- 사용 가능한 모델명은 `client.models.list()`로 확인할 수 있습니다.
- 프로그램을 켜면 키가 없는지 상태 줄에서 바로 알려 줍니다.

`.gitignore` 예시:

```gitignore
.env
results/
__pycache__/
```

> ⚠️ **보안 주의**: `.env`에는 실제 API 키가 들어 있으므로 Git 저장소에 커밋하거나 타인에게 공유하지 마세요.

## 6. 사용 방법

```bash
python travel_recommender_gui.py
```

1. 창이 열리면 **년/월/일**을 선택합니다. (기본값은 오늘)
2. `🔍 추천받기` 버튼(또는 Enter 키)을 누릅니다.
3. 진행 바와 상태 줄에서 `[1/3] → [2/3] → [3/3]` 단계를 확인합니다.
4. 완료되면 **요약 / 맛집 / 리포트** 탭에서 결과를 확인합니다.
5. 필요하면 `📂 결과 폴더 열기`로 저장된 파일을 열거나 `📋 리포트 복사`로 내용을 복사합니다.

### 입력 확인

| 상황 | 동작 |
|---|---|
| 존재하지 않는 날짜 (예: 2월 30일) | 경고 창을 띄우고 실행하지 않음 |
| 이미 지난 날짜 | "그래도 계속할까요?" 확인 창 |
| 실행 중에 다시 누름 | 무시 (추천 버튼은 실행 중 비활성화) |

## 7. 결과물

실행이 끝나면 `results/` 폴더에 실행 시각 기준으로 파일 2개가 생성됩니다.

1. `result_YYYYMMDD_HHMMSS.json`: AI 추천 결과, 맛집 검색 결과, 오류 기록(`errors`)을 담은 원본 데이터
2. `report_YYYYMMDD_HHMMSS.md`: 추천 이유, 날씨, 행사, 맛집, 하루 일정이 정리된 마크다운 리포트

> 날씨와 행사는 AI가 생성한 **일반적인 정보**입니다. 실시간 예보가 아니므로 방문 전에 꼭 확인하세요.

## 8. 동작 방식

### 8-1. 처리 흐름

1. **AI 추천 (Gemini 1회 호출)**: 도시, 날씨, 행사, 이유, 하루 일정을 한 번에 요청합니다. 응답 구조는 Pydantic 스키마(`response_schema`)로 고정합니다.
2. **맛집 검색 (카카오 로컬 API)**: `"{도시} 맛집"`을 음식점 카테고리(`FD6`)로 제한해 5곳을 조회합니다.
3. **리포트 생성 (로컬)**: AI를 다시 호출하지 않고 파이썬이 직접 마크다운을 만듭니다. 호출 횟수와 할당량 사용이 줄고 형식이 항상 같습니다.

### 8-2. 창이 멈추지 않는 구조

GUI 프로그램은 화면을 그리는 **메인 스레드**가 오래 걸리는 작업을 하면 창이 "응답 없음" 상태가 됩니다. 이 프로그램은 다음과 같이 역할을 나눕니다.

```text
[메인 스레드: 화면]                     [작업 스레드: 네트워크]
 추천받기 클릭 ──스레드 시작──────────▶ Gemini 호출 → 카카오 호출 → 저장
       ▲                                         │
       └──── 100ms 마다 큐(Queue) 확인 ◀── 상태·결과·오류 메시지 전달
```

- 작업 스레드는 화면을 직접 건드리지 않고 **큐에 메시지만** 넣습니다.
- 메인 스레드가 0.1초마다 큐를 읽어 상태 줄, 결과 탭, 오류 창을 갱신합니다. (tkinter는 여러 스레드에서 화면을 직접 바꾸면 불안정하기 때문입니다.)

### 8-3. 오류 처리 정책

| 상황 | 동작 |
|---|---|
| 429 / 500 / 503 (한도 초과, 서버 혼잡) | 서버 권장 대기시간 또는 6초, 12초 순으로 최대 3회 재시도. 상태 줄에 카운트다운 표시 |
| 서버 권장 대기시간이 90초 초과 | 일일 할당량 소진으로 보고 재시도 없이 안내 |
| 400 / 401 / 403 (키 오류) | 재시도 없이 "API 키 확인" 팝업 |
| 404 (모델명 오류) | 재시도 없이 `GEMINI_MODEL` 확인 팝업 |
| AI 응답 형식 오류 | 대기 없이 즉시 안내 |
| 카카오 API 실패 / 키 없음 | 맛집을 "데이터 없음"으로 처리하고 리포트는 정상 생성. 요약 탭에 경고를 표시하고 오류는 JSON의 `errors`에 기록 |

AI 추천이 실패했을 때 임의의 도시(예: 서울)로 대체하지 않습니다. 사용자가 잘못된 추천을 받는 일을 막기 위해서입니다.

## 9. CLI 버전

터미널에서 쓰는 버전도 같은 방식으로 동작합니다.

```bash
python main.py --date 2026-10-15    # 날짜 지정
python main.py -d 2026-10-15        # 짧은 옵션
python main.py                      # 날짜를 물어봄 (엔터 = 오늘)
```

긴 옵션은 하이픈 **두 개**(`--date`)입니다. 하이픈 하나짜리 `-date`는 `-d` + `ate`로 해석되어 오류가 납니다.

## 10. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 실행 시 `ModuleNotFoundError` | `pip install google-genai python-dotenv requests` 실행 |
| `No module named 'tkinter'` | Python 설치 시 tcl/tk 옵션이 빠진 경우입니다. Python 설치 프로그램을 다시 실행해 `tcl/tk and IDLE`을 선택하세요. |
| 상태 줄에 "GEMINI_API_KEY 가 없습니다" | `.env` 위치(프로그램과 같은 폴더), 변수 이름, 오타를 확인하세요. |
| 팝업: 오류 코드 404 | 모델명이 올바르지 않습니다. `GEMINI_MODEL`을 확인하세요. |
| 팝업: 오류 코드 429 | 사용 한도 초과입니다. 잠시 후 또는 내일 다시 시도하세요. |
| 맛집 탭이 "데이터 없음" | 카카오 키가 REST API 키인지 확인하고, 결과 JSON의 `errors` 항목을 확인하세요. |
| CLI에서 `argument -d/--date: ... 'ate'` | `-date` 대신 `--date` 또는 `-d`를 사용하세요. |

## 11. 학습 포인트

### ① REST API와 HTTP 메서드 (GET / POST)
- **GET**: 서버의 데이터를 조회할 때 사용하며, 요청 값이 URL 쿼리에 들어갑니다. (예: 카카오 로컬 검색으로 맛집 조회)
- **POST**: 서버에 데이터를 보내 처리를 요청할 때 사용하며, 요청 값이 본문(Body)에 들어갑니다. (예: Gemini에 프롬프트를 보내 응답 생성)

### ② LLM 출력의 구조화 (JSON 스키마)
- AI 응답을 자유 텍스트가 아닌 JSON으로 받으면 `recommended_city` 같은 값을 정확히 꺼내 다음 단계(맛집 검색)의 입력으로 넘길 수 있습니다.
- 프롬프트로 "JSON으로 답해 달라"고 부탁하는 것보다 `response_schema`로 구조를 강제하는 편이 파싱 오류가 훨씬 적습니다.

### ③ 외부 API 오류 처리 원칙
- 오류의 **종류에 따라** 대응을 다르게 합니다. 일시적 오류(429/503)는 재시도하고, 영구적 오류(키·모델명 문제)는 즉시 원인을 알려 줍니다.
- 부가 기능(맛집)이 실패해도 핵심 결과(추천 리포트)는 제공하고, 핵심 기능(AI 추천)이 실패했는데 성공한 것처럼 보이게 하지는 않습니다.

### ④ GUI 프로그래밍 기초 (tkinter)
- **이벤트 기반**: 프로그램은 `mainloop()`에서 버튼 클릭, 키 입력 같은 이벤트를 기다리다가 해당 함수를 실행합니다.
- **스레드와 큐**: 오래 걸리는 작업은 별도 스레드로 분리하고, 화면 갱신은 메인 스레드만 하도록 큐로 결과를 넘깁니다.
- **위젯 조합**: `Combobox`(선택), `Progressbar`(진행), `Notebook`(탭), `Treeview`(표) 등 기본 위젯만으로도 실용적인 화면을 만들 수 있습니다.

### ⑤ 역할 분리
- 판단과 창작이 필요한 부분(추천, 일정)만 AI에 맡기고, 정해진 형식의 문서 생성은 코드로 처리합니다. 비용이 줄고 결과가 안정적입니다.

### ⑥ 환경변수(.env)로 비밀 정보 관리
- API 키를 소스코드에 넣지 않고 `.env`로 분리하면 코드가 유출되어도 키는 지킬 수 있고, 무단 과금 같은 사고를 막을 수 있습니다.

### ⑦ 사용자 경험(UX)
- 입력을 드롭다운으로 제한해 실수를 줄이고, 진행 단계와 대기 카운트다운을 보여 주며, 오류는 "무엇이 문제이고 어떻게 고치는지"를 함께 알려 줍니다.

## 12. 한계와 향후 개선

| 항목 | 내용 |
|---|---|
| 날씨·행사 정확도 | AI가 만든 일반 정보이며 실시간 예보가 아닙니다. 기상청 예보 API나 검색 연동을 붙이면 개선할 수 있습니다. |
| 추천 다양성 | 같은 날짜를 반복 실행하면 다른 도시가 나올 수 있습니다. 지역·테마 선택 옵션을 추가할 수 있습니다. |
| 기록 보기 | 현재는 저장된 파일을 폴더에서 열어야 합니다. 과거 결과를 프로그램 안에서 불러오는 기능을 추가할 수 있습니다. |
| 배포 | Python이 설치된 환경에서 실행합니다. 실행 파일(.exe)로 묶는 방식은 `.env`와 `results/` 위치를 따로 설계해야 합니다. |
